# Manual do usuário

O manual do produto está em **[`manual.html`](manual.html)** — um único arquivo, sem dependências.

- **Ler:** abra `manual.html` em qualquer navegador.
- **PDF:** abra no navegador e use *Imprimir → Salvar como PDF* (recomendado: Chrome/Edge, com "Gráficos de fundo" ligado).

As figuras não são capturas de tela: são renderizadas com o **mesmo CSS do painel** (`tools/webui/static/index.html`), então mostram exatamente o que aparece na interface. Se a webui mudar de aparência, atualize os blocos `.wui` do `manual.html` a partir do `<style>`/markup de lá.

O `README.md` na raiz do projeto é a documentação técnica (firmware, protocolo, build); este manual é para o operador/instalador.
